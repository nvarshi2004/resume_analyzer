You are a senior full-stack developer and software architect.

Build a complete web application called **"Resume Gap Analyzer"** using:

* Backend: Node.js with Express
* Frontend: HTML, CSS, JavaScript (no frameworks)
* Add PDF upload support
* No external APIs (NO ChatGPT, NO paid services)
* Use rule-based ATS-like logic

---

🎯 APPLICATION GOAL:
The app should take:

* Resume (TEXT or PDF upload)
* Job Description (TEXT)

And output:

* Match Score (%)
* Fit Label (Strong / Moderate / Weak)
* Missing Skills
* Weaknesses
* Suggestions for improvement

Install:

---

📌 ENDPOINTS:

1. POST /analyze

   * Input: resume text + job description

2. POST /upload

   * Accept PDF file
   * Extract text using pdf-parse
   * Return extracted text

---

🧠 ANALYSIS LOGIC:

1. Keyword Extraction:

* Lowercase
* Remove special characters
* Remove stopwords
* Return unique keywords

2. Match Score:

* (matched / JD keywords) * 100

3. Weakness Detection:

* Missing skills
* If missing > 50% → "Low Relevance"
* If no numbers (%) → "No Metrics"

4. Suggestions:

* Missing Skills → "Add relevant projects"
* No Metrics → "Add quantified results"
* Low Relevance → "Customize resume"

5. Fit Label:

* 80+ → Strong
* 60–79 → Moderate
* <60 → Weak

---
